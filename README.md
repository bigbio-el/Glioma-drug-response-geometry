# Glioma drug-response geometry

MATLAB code for **Single-cell geometry of drug responses across malignant glioma states**.

## Files

- `gbm_drug_geometry_analysis_reviewer_ready.m` — main analysis
- `inspect_glioma_loom.m` — loom inspection
- `results/` — cross-drug summary tables

## Data

Public glioma scRNA-seq data from Levitin et al. (2023), including GSE148842.

doi: 10.1101/2023.12.05.570193

## Run

Download the integrated loom file and run:

`gbm_drug_geometry_analysis_reviewer_ready`

Results are written to the `results` folder.
